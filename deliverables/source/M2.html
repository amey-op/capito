TEAM NUMBER: 028Megathon X: Singularity · M2 Progress

Capito: learn money by growing a practice portfolio

Vanguard India brief: digital financial literacy for Grade 11–12 students in Hyderabad. Status at M2 (11 Oct).

1. What changed since M1

  • Name settled: the working name is now the product name, Capito, across the app, page title, saved-game keys and docs.
  • Built, not just designed: all 29 lessons, the simulation engine, 25 life events with consequences, the portfolio and Plan the Month, every calculator, Scam Shield, the lesson player, the home page, the Word Bank and the end-of-game summary now exist as working code.
  • One lesson player for every lesson: gut-check, 5–8 swipe cards with tap-to-open Word Bank terms, tap-sort and reveal activities, an embedded tool (Scam Shield runs inside lesson 8.1), a 3-question quiz with teaching feedback, then practice money and Plan the Month. Lesson 9.1 adds the 10-question final quiz.
  • A full loop: lesson → practice money → Plan the Month → the month closes → that lesson's life events → the next lesson. The home page's Continue button always points to the next step.
  • How we check work: each pull request runs typecheck, all tests and a production build locally before it is merged with a merge commit; main has stayed buildable after every merge.
  • Two portals: a start page with two doors. The Student app is the game; the NGO view shows what a partner NGO would see for a class: progress and quiz scores by level, weak spots (the risky first choices), scam safety and a nickname-only learner table with CSV export. For the demo it runs on a sample class, with this device added as one live learner; there is no login yet.
  • Hindi and Telugu: a language switch in the header. Screens, the portfolio and Level 1 are translated, with the English money term kept beside each translation and a "draft translation" note; untranslated text falls back to English.
  • Not built yet: real accounts with class codes and server sync, offline install and hosting. We demo from a local build.
