# Capito: demo script (target 3:40, hard limit 4:00)

Record the screen at phone size (about 390 px wide, browser device mode) except where it says laptop. Voice-over in plain English; no names, team name or college on screen or in the voice-over. Start from a fresh game (clear site data) and keep a second browser profile with a game already advanced to Level 4 and Level 6, so you can jump instead of playing every lesson on camera.
